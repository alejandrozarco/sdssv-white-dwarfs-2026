# WDJ221519.86+253059.05 (Gaia DR3 1879989790567353344)

## Day-scale periods of hot white dwarfs

GALEX J221519.8+253059; spectral type DOZ (MWDD). G = 17.05, 1190 pc. Ranaivomanana et al. (2025) list different periods (Gaia 0.077198 d, TESS 18.565 d, type unclear); the Gaia DR3 spurious-signal table lists 1.29438 c/d, the first harmonic of this period.

**Measurement.** P = 37.07929 ± 0.00104 h (ZTF, n = 2716, BJD 2458218.987-2460969.789); semi-amplitude 1.4% ± 0.1%.
